# Project ForgetMeNot
This is a story-driven experience aimed at school-going children with a view to popularizing space science and engineering among them. It is designed to solve the "Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars" challenge of NASA Space Apps Challenge 2026.

Data Source: 
NASA

Tech Stack:
HTML5, CSS, Typescript
Deployed via Lovable
